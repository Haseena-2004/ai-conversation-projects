How it works

The model returns JSON with a fixed label set, so outputs can be measured. Guardrails: the model must not offer discounts or terms not mentioned in the call, and a rule-based checker flags any NBA message containing a number or offer word that is not in the transcript. It also flags escalations (threats, abuse), a confidence score, and low-confidence calls for human review; wrong-number and hostile customers get no follow-up. Limits: only 3 calls here (price objection, EMI promise in Hinglish, angry customer), so treat the percentages as a demo, not proof (the full pipeline script runs 30+ calls); intent labels overlap (e.g. a price objection can be "interested" or "not interested"), which is itself a finding for label design.
